Core Machine Learning Research

Self-Supervised Spatiotemporal Masked Autoencoders for Few-Shot Cardiac Sequence Analysis

In Preparation (Targeting NeurIPS ML4H 2025) | Sole Author

Developing a novel 3D Spatiotemporal Masked Autoencoder (MAE) to address catastrophic overfitting in low-resource sequential medical imaging. By masking 75% of the spatiotemporal MRI patches, the model self-supervises the reconstruction of hidden physiological structures, learning robust kinematic representations of the cardiac cycle without downstream targets.

Automated Coronary Artery Disease Detection Using a CNN Model with Temporal Attention

medRxiv Preprint (Feb 2026) | Co-Author / ML Engineer

Engineered the 2D spatial feature extraction pipeline and optimization loop for a CNN-LSTM architecture designed to detect CAD from sequential coronary angiograms. Developed the PyTorch data ingestion module to convert raw DICOM files to normalized tensors and implemented the baseline training loop (BCE Loss, Adam Optimizer), contributing to a model achieving an AUC of 0.9982.

Harvard/MIT Collaboration | Published in JPHMP / JAMA
